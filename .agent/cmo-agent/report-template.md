# Marketing Report Template — CMO Agent

File: `.agent/cmo-agent/reports/report-YYYY-MM-DD-<slug>.md`

```markdown
# Marketing Briefing — <slug>

**Date:** YYYY-MM-DD
**Goal:** <one line from the brief>
**Period:** <campaign window>
**Status:** ready to produce | needs direction | research only

## TL;DR

3–5 sentences. What the research showed, how the calendar is shaped,
the single most important recommendation. No filler.

## Snapshot

| Item | Count |
|------|------:|
| Public sources reviewed | N |
| Competitor / theme patterns noted | N |
| Posts in calendar | N |
| Drafts ready | N |
| Languages | sq / en |

## Theme findings

- 3–6 bullets. Each bullet: pattern + why it matters for our academies +
  source URL. No generic "AI is hot" filler.

## Calendar outline

| Week | Focus | Posts | Channels | Goal of the week |
|------|-------|------:|----------|------------------|
| 1 | ... | 3 | IG, LI | ... |

## Draft status

- List which posts already have full drafts in `content-planner/output/.../drafts/`.
- One line each: date, channel, hook (first 8 words).

## Risks / notes

- Fact-check flags, production constraints, brand risks.
- Empty section is fine.

## Recommended next move

One paragraph. Exactly one action for the human or orchestrator.
```

## Tone

Executive, plain, short sentences. Numbers first. No hype adjectives. No emoji.
No bold labels on every line.
