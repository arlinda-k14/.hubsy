Widget Preview

Hubsy test page

Free, static, client-side preview of the Hubsy chat widget for Creative Hub Kosovo. The floating button at the bottom-right opens the assistant. No backend and no Blaze plan required — answers are read straight from knowledge-base.json.

How to use

  1. Click the Hubsy button in the bottom-right corner.
  2. Ask about the academies — courses, schedules, tuition, certifications.
  3. Facts are quoted from knowledge-base.json; unknown questions fall back to the contact details.

Client-side mode (default)

With endpoint: "" the widget loads knowledge-base.json from the same host as chatbot.js and answers locally with a retrieval engine. This is what makes the free static deploy work — no server needed.

Embed on WordPress

Paste this into the site footer (Appearance → Theme File Editor → footer.php, or a custom HTML/script widget). Change the host to wherever this folder is deployed:

<script>window.HUBSY_CONFIG={endpoint:""};</script>
<script src="https://YOUR-HOST/chatbot.js" defer></script>

Optional backend

To upgrade to LLM answers, deploy the Firebase Function and set window.HUBSY_CONFIG.endpoint to https://europe-west1-creative-hub-2026.cloudfunctions.net/hubsyChat. The widget then POSTs { message, history } and reads reply.
