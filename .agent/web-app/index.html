Widget Preview

Hubsy test page

Local preview of the Hubsy chat widget for Creative Hub Kosovo. The floating button at the bottom-right opens the assistant. Nothing is deployed from this page.

How to use

  1. Click the Hubsy button in the bottom-right corner.
  2. Ask about the academies — courses, schedules, tuition, certifications.
  3. Answers come from knowledge-base.json; unknown questions fall back to the contact details.

Connecting a backend

This page ships with endpoint: "", so the widget replies with the polite fallback message. Point it at your Firebase Function by setting the config before chatbot.js loads:

Set window.HUBSY_CONFIG.endpoint to your Firebase Function URL (e.g. https://<region>-<project>.cloudfunctions.net/hubsyChat). The widget POSTs { message, history } and reads reply from the response.
