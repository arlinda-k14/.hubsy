Parapamje e Widget-it

Hubsy — asistenti AI

Parapamje e widget-it të chatit të Hubsy për Creative Hub Kosovo. Butoni rrethues poshtë djathtas hap asistentin. Pa backend dhe pa plan Blaze: përgjigjet lexohen direkt nga knowledge-base.json. Hubsy përgjigjet gjithmonë në shqip.

Si ta përdorni

  1. Klikoni butonin Hubsy në këndin poshtë djathtas.
  2. Pyetni për akademitë: kurse, orare, çmime, certifikata.
  3. Faktet citohen nga knowledge-base.json; pyetjet e panjohura kalojnë te kontaktet e kolegeve.

Metoda pa backend (by default)

Me endpoint: "" widget-i ngarkon knowledge-base.json nga i njëjti host si chatbot.js dhe përgjigjet lokalisht me një motor kërkimi. Kjo e bën të mundur deploy-in falas pa server.

Vendosni në WordPress

Ngjitni këtë në fund të faqes (Appearance → Theme File Editor → footer.php, ose një widget HTML/script i personalizuar). Ndërroni hostin me atë ku është deployuar ky folder:

<script>window.HUBSY_CONFIG={endpoint:""};</script>
<script src="https://HOST-I-TU/chatbot.js" defer></script>

Backend i padhomatshëm

Për përgjigje nga modeli i gjuhës, deploy-oni Firebase Function dhe vendosni window.HUBSY_CONFIG.endpoint në https://europe-west1-creative-hub-2026.cloudfunctions.net/hubsyChat. Widget-i dërgon { message, history } dhe lexon reply.
